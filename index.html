Política de Privacidad de VenciPharma

Última actualización: Octubre de 2026

La aplicación móvil VenciPharma (en adelante, "la Aplicación"), desarrollada por Minase Technologies, respeta la privacidad de sus usuarios y se compromete a proteger cualquier información relacionada con el uso de la misma.

1. Recopilación y almacenamiento de datos

Almacenamiento Local (Local-First): Todo el inventario, fechas de vencimiento, nombres de medicamentos, laboratorios y políticas comerciales ingresadas por el usuario se almacenan de manera local y exclusiva en el dispositivo móvil mediante una base de datos interna SQLite/Room. La Aplicación no transfiere, no sincroniza ni almacena el inventario del usuario en ningún servidor externo propio ni en la nube.

2. Permisos del Dispositivo

  • Cámara: Se utiliza exclusivamente para la lectura en tiempo real de códigos de barras y el reconocimiento óptico de caracteres (OCR) en empaques de medicamentos mediante las librerías oficiales de Google ML Kit. Las imágenes procesadas no se envían a servidores de Minase Technologies ni se almacenan permanentemente fuera del dispositivo.
  • Acceso a Internet y Red: Se requiere para consultar directorios públicos de productos y autocompletar el nombre comercial de los medicamentos escaneados, así como para la carga de publicidad a través de Google AdMob.

3. Servicios de Terceros y Publicidad

La Aplicación utiliza servicios de terceros que pueden recopilar información anónima utilizada para identificar dispositivos, métricas de rendimiento y entrega de anuncios:

  • Google AdMob: Utilizado para monetización mediante anuncios publicitarios. AdMob puede recopilar identificadores de publicidad móvil (Advertising ID), datos de diagnóstico y ubicación aproximada para fines de visualización de anuncios y prevención de fraudes conforme a las políticas de privacidad de Google. (Política de Privacidad de Google Ads).
  • Google Play Services / Google ML Kit: Utilizados para el escaneo de códigos de barras y visión artificial en el dispositivo.

4. Exportación e Importación de Datos

La Aplicación permite al usuario exportar e importar copias de seguridad de su inventario en formato JSON. Esta acción es iniciada voluntariamente por el usuario y el archivo generado queda bajo el control exclusivo del usuario para guardarlo o compartirlo mediante sus propias aplicaciones autorizadas.

5. Seguridad de los Datos

Dado que los datos del inventario residen en el almacenamiento interno de la Aplicación en el dispositivo, la seguridad del inventario depende de las medidas de bloqueo y seguridad configuradas por el usuario en su propio teléfono móvil.
